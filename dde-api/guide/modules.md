# 导出类型介绍

dde-api 提供 C++ header-only 事件日志记录接口，以及图片模糊处理、显示器配置、输入设备配置、声音主题播放、光标设置、窗口管理器兼容性检查、Status Notifier Item 代理、区域设置辅助、主题设置、音效设置和 X 事件监视的 Go 工具程序。

## DDE_EventLogger

### 定位

C++ header-only 事件日志记录接口，面向需要将事件日志发送到后端的调用者。

### 功能能力总结

提供将事件日志发送到后端服务的能力。调用者通过包含头文件即可使用，无需链接库文件。

### 使用场景

需要在 C++ 程序中记录并发送事件日志时。

## blurimage

### 定位

图片模糊处理的 Go 工具程序。

### 功能能力总结

对输入图片执行模糊处理，生成模糊后的图片。

### 使用场景

需要生成壁纸或背景的模糊效果时。

## drandr

### 定位

显示器配置的 Go 工具程序，基于 RandR 协议。

### 功能能力总结

查询和设置显示器的分辨率、刷新率、布局和方向。

### 使用场景

需要编程方式配置显示器输出参数时。

## dxinput

### 定位

输入设备配置的 Go 工具程序。

### 功能能力总结

查询和设置输入设备（鼠标、触摸板、键盘、触摸屏）的属性和参数。

### 使用场景

需要配置输入设备行为时。

## sound-theme-player

### 定位

声音主题播放的 Go 工具程序。

### 功能能力总结

按 freedesktop 声音主题规范查找并播放指定事件的声音。

### 使用场景

需要在程序中播放系统声音主题中的事件音效时。

## cursor

### 定位

光标设置的 Go 工具程序。

### 功能能力总结

设置系统鼠标光标主题和大小。

### 使用场景

需要编程方式修改系统光标主题时。

## wmcompatible

### 定位

窗口管理器兼容性检查的 Go 工具程序。

### 功能能力总结

检测当前运行的窗口管理器并判断其兼容性。

### 使用场景

需要根据窗口管理器类型调整程序行为时。

## sni_stub

### 定位

Status Notifier Item 代理的 Go 工具程序。

### 功能能力总结

作为 Status Notifier Item 协议的代理，转发状态通知项信息。

### 使用场景

需要处理或转发系统托盘状态通知项时。

## localehelper

### 定位

区域设置辅助的 Go 工具程序。

### 功能能力总结

查询和设置系统区域和语言环境。

### 使用场景

需要获取或修改系统区域设置时。

## theme

### 定位

主题设置的 Go 工具程序。

### 功能能力总结

设置系统的 Gtk 主题、图标主题和光标主题。

### 使用场景

需要编程方式修改系统主题时。

## soundeffect

### 定位

音效设置的 Go 工具程序。

### 功能能力总结

启用、禁用和配置系统音效。

### 使用场景

需要控制系统音效开关或配置时。

## xevent_monitor

### 定位

X 事件监视的 Go 工具程序。

### 功能能力总结

监听 X Window 系统中的键盘、鼠标和触摸事件，支持按键和按键组合的监视。

### 使用场景

需要监听全局 X 输入事件时。

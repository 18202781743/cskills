# 导出类型介绍

dde-polkit-agent 提供认证代理扩展接口，允许第三方扩展认证行为，包括声明感兴趣的认证动作、通过代理对象获取认证信息（动作 ID、用户名、密码），以及认证代理的初始化与释放。

## AgentExtension

### 定位

认证代理扩展接口，面向需要自定义认证行为的调用者。调用者通过继承此接口并实现接口方法，将自定义认证逻辑接入 dde-polkit-agent。

### 功能能力总结

- 使用代理对象初始化扩展
- 释放扩展资源
- 声明感兴趣的认证动作 ID 列表
- 返回扩展的描述信息

### 使用场景

需要为特定 Polkit 认证动作添加自定义认证逻辑时。

## AgentExtensionProxy

### 定位

扩展代理接口，面向已注册的扩展插件，提供获取当前认证上下文信息的能力。

### 功能能力总结

- 返回当前认证动作的 ID
- 返回认证用户名
- 返回用户输入的密码

### 使用场景

扩展插件需要获取当前认证动作 ID、用户名或密码时。

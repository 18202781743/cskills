# 导出类型介绍

dde-shell 的 QML 模块 `org.deepin.ds` 提供 Applet 根元素、Containment 根元素、Panel 附加属性、Layer Shell 窗口属性、全局 DS 对象、拖拽属性、弹出窗口和列表转表格代理模型。

## org.deepin.ds

### 定位

dde-shell 的 QML 模块，URI 为 `org.deepin.ds`，导入版本 1.0。提供 Applet 插件的 QML 根元素、Containment 插件的 QML 根元素、Panel 附加属性、Layer Shell 窗口属性控制和全局 DS 对象，以及拖拽、弹出窗口和代理模型等辅助类型。

### AppletItem

#### 定位

Applet 插件的 QML 根元素，提供 `Applet` 附加属性（包括 `pluginId`）。

#### 功能能力总结

- 作为 Applet 插件 QML 界面的入口根元素，将 QML 视图树与对应的 C++ 插件实例绑定
- 通过附加属性向 QML 层暴露当前插件的插件 ID 和关联的 Applet 对象，使 QML 代码能够识别自身所属的插件上下文

#### 使用场景

开发 Applet 插件的 QML 界面时，作为根元素使用。

### ContainmentItem

#### 定位

Containment 插件的 QML 根元素，提供 `Containment.appletItems` 模型供 Repeater 渲染子 item。

#### 功能能力总结

- 作为容器插件的 QML 界面入口，同时承担子插件 UI 元素的容器职责
- 通过附加属性暴露子 Applet 项模型，使 QML 层能够以标准列表模型的方式遍历和渲染所有子插件的 UI 元素

#### 使用场景

开发 Containment 插件的 QML 界面并需要渲染子 Applet 时。

### Panel

#### 定位

Panel 附加属性类型，不可实例化，通过附加属性使用。提供 Panel 面板的弹出窗口、提示窗口和菜单窗口访问能力，继承 Containment 的子 Applet 项模型和 Applet 的插件 ID、根对象等属性。

#### 功能能力总结

- 为面板内子插件提供对所属面板窗口资源的访问能力，包括弹出窗口、提示窗口和菜单窗口，使子插件能够在面板上下文中创建和管理浮层交互
- 继承容器的子插件项模型，使面板内子插件同样能够获取同级子插件的 UI 元素列表
- 继承 Applet 的身份属性和根对象引用，保持插件上下文信息的一致性传递

#### 使用场景

开发 Dock、顶栏这类 Panel 面板插件的子插件时，通过附加属性访问所属 Panel 的窗口和属性。

### DLayerShellWindow

#### 定位

Layer Shell 附加属性类型，控制 Wayland 窗口的锚定方向、层级和边距。

#### 功能能力总结

- 控制 Wayland Layer Shell 窗口的屏幕锚定方向（顶部、底部、左侧、右侧的任意组合），实现面板类窗口贴边显示
- 设置窗口在 Wayland 合成器中的层级（背景层、底层、顶层、覆盖层），控制窗口之间的堆叠顺序
- 配置窗口各方向的边距和独占区域宽度，管理窗口与屏幕边缘的间距以及与其他窗口的空间协调
- 控制窗口的键盘交互模式（无焦点、独占焦点、按需焦点），满足面板在不同交互场景下的输入需求
- 设置窗口的期望尺寸和输入区域，支持按需裁剪窗口的响应范围

#### 使用场景

需要控制插件窗口在 Wayland Layer Shell 中的位置和层级时。

### DS

#### 定位

QML 全局单例对象，提供跨插件访问和窗口管理能力。

#### 功能能力总结

- 以插件 ID 为索引，在 QML 层跨插件查找和访问其他插件实例的代理对象，支持获取单个实例或全部实例列表
- 提供根 Applet 对象的访问入口，使 QML 代码能够获取整个插件树的根节点
- 管理指定窗口的子窗口关闭操作，支持批量清理面板下已打开的浮层窗口
- 提供全局键盘和鼠标抓取能力，使特定窗口能够独占输入设备
- 支持延时回调机制，在指定时间后执行 QML 侧的 JavaScript 函数

#### 使用场景

需要在 QML 中访问其他插件实例的属性或方法，或需要管理窗口焦点和子窗口时。

### DQuickDrag

#### 定位

拖拽附加属性类型，不可实例化，通过附加属性使用。提供拖拽操作的覆盖窗口、拖拽起点和当前点追踪能力。

#### 功能能力总结

- 追踪拖拽操作的完整轨迹，记录拖拽起始坐标和实时拖拽当前坐标，为拖拽过程中的视觉反馈提供位置数据
- 在拖拽期间创建和管理独立的覆盖窗口，用于渲染拖拽预览组件，使拖拽视觉效果不受原窗口边界限制
- 支持自定义拖拽热点的缩放比例，精确控制拖拽预览与指针的相对偏移
- 提供拖拽激活状态的查询能力，使 QML 层能够根据拖拽状态动态切换交互行为

#### 使用场景

需要在 QML 中实现自定义拖拽交互并显示拖拽覆盖层时使用。

### PopupWindow

#### 定位

弹出窗口类型，继承自 QQuickApplicationWindow，可实例化。提供设置窗口几何位置和 X11 平台下的焦点抓取转换能力。

#### 功能能力总结

- 提供可实例化的自定义弹出窗口，支持设置瞬态父窗口和窗口几何位置，满足面板插件创建自定义浮层交互的需求
- 自动管理窗口尺寸约束，将最小尺寸限制为 1x1 以避免 Wayland 协议错误，将最大尺寸限制为屏幕尺寸以防止显存溢出
- 在 X11 平台上监听原生焦点事件，识别因键盘抓取导致的焦点切换（如输入法弹出），并通过信号通知 QML 层以便正确处理焦点状态变化
- 自动处理 Popup 类型窗口的点击外部关闭行为，同时区分拖拽和点击操作避免误关闭

#### 使用场景

需要创建自定义弹出窗口并控制其几何位置和焦点行为时使用。

### DListToTableProxyModel

#### 定位

列表转表格代理模型，可实例化，继承自 KExtraColumnsProxyModel。将单列列表模型扩展为多列表格模型，按指定角色添加额外列。

#### 功能能力总结

- 将单列列表模型转换为多列表格模型，根据指定的角色列表自动为每一行添加额外的数据列
- 支持指定源模型中的列作为基础列，在保持源模型数据不变的前提下扩展表格结构

#### 使用场景

需要将单列列表模型转换为多列表格模型供表格视图使用时。

# dde-qtplatform-plugins 二次开发文档 · 概览

## 项目定位

dde-qtplatform-plugins 是 DTK 的 Qt 平台插件（QPA）项目，为 Qt 应用程序在 DDE 桌面环境中运行时提供平台级的窗口管理集成。项目以 Qt 插件形式构建和安装，由 Qt 运行时在启动阶段自动加载，不作为链接库供使用方工程直接引用。

## 功能能力

- 提供 XCB 平台插件，在 X11 环境下为 Qt 应用提供窗口圆角、模糊效果、阴影、窗口装饰方面的 DTK 风格的平台级视觉集成。
- 提供 Wayland 平台插件（仅 DTK5），在 Wayland 环境下提供相应的窗口管理集成。
- 通过平台插件机制拦截和增强 Qt 的窗口创建、绘制和事件处理流程，使标准 Qt 控件获得 DTK 外观。

## 术语与缩写

- **QPA**：Qt Platform Abstraction，Qt 平台抽象层，Qt 通过该接口适配不同窗口系统。
- **XCB**：X C Binding，X11 协议的 C 语言绑定，本项目 XCB 插件基于此实现。
- **平台插件**：以共享库形式安装到 Qt 插件目录的 QPA 插件，由 Qt 运行时按平台名称自动加载。

## 全局约定

平台插件为运行期组件，不需要使用方工程在编译或链接阶段引入。插件安装在 Qt 的平台插件目录中，由 Qt 根据平台名称自动选择加载。集成方式参见[集成与构建配置](integration.md)。

本项目不对外导出可供使用方工程直接引用的 C++ 类型。参见[导出类型介绍](modules.md)。

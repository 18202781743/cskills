# dde-qtintegration 二次开发文档 · 概览

## 项目定位

dde-qtintegration 是 DTK 的 Qt 风格集成插件项目，为 Qt 应用程序在 DDE 桌面环境中运行时提供样式、图标引擎、图片格式和平台主题方面的集成。项目以 Qt 插件形式构建和安装，由 Qt 运行时按插件类型自动加载，不作为链接库供使用方工程直接引用。

## 功能能力

- 提供样式插件，使 Qt Widgets 应用程序获得 DTK 视觉风格。
- 提供图标引擎插件，支持 DCI 图标和 SVG 图标的渲染。
- 提供图片格式插件，支持 DCI 图片格式和 SVG 图片格式的加载。
- 提供平台主题插件，为 Qt 应用程序提供文件对话框、主题设置等 DDE 桌面环境集成。

## 术语与缩写

- **DTK**：Deepin Tool Kit。
- **DTK5 / DTK6**：分别与 Qt5 / Qt6 配套的主版本。
- **DCI**：将多份图标数据组织在单个文件中的格式，支持多主题、多分辨率、多状态。
- **样式插件**：以共享库形式安装到 Qt 样式插件目录的插件，由 Qt 运行时按样式名称自动加载。

## 全局约定

所有插件为运行期组件，不需要使用方工程在编译或链接阶段引入。插件安装在 Qt 的对应插件目录中，由 Qt 运行时自动加载。集成方式参见[集成与构建配置](integration.md)。

本项目不对外导出可供使用方工程直接引用的 C++ 类型。参见[导出类型介绍](modules.md)。

# dde-session-ui 二次开发文档 · 概览

## 项目定位

dde-session-ui 是 DDE 会话 UI 组件集合，提供多种独立运行的对话框和工具程序，包括黑屏遮罩、蓝牙对话框、触摸屏校准对话框、许可证对话框、图片混合工具、窗口管理器选择器、提示对话框、欢迎页面、挂起确认对话框、OSD 通知、低电量警告、警告对话框、切换到 Greeter 和内存警告对话框。各组件通过命令行调用运行。

## 术语与缩写

- **OSD**：On-Screen Display，屏幕显示通知。
- **Greeter**：登录管理器的前端界面程序。

## 导出类型

[导出类型介绍](modules.md)是本项目唯一的类型参考文档。以组件名为章节，逐一说明各组件的定位、功能能力和使用场景。

## 全局约定

dde-session-ui 不安装公共开发头文件，不导出 C++ 命名空间或 CMake 库目标。各组件为独立可执行程序，使用方通过命令行调用运行。部分组件消费 DBus 服务但不导出 DBus 接口。

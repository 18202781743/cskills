# 导出类型介绍

dde-application-manager 通过 DBus 接口提供应用启动、应用停止、应用状态查询、应用添加与移除、应用隐藏与显示、剪贴板访问请求、异步操作跟踪、应用对象列表管理能力。

## org.desktopspec.ApplicationManager1

### 定位

应用管理主接口，面向需要启动应用、管理应用列表和查询应用状态的调用者。

### 功能能力总结

- 启动应用
- 通过 desktop file 启动应用
- 标识应用
- 添加应用到启动器
- 从启动器移除应用
- 隐藏应用
- 显示应用
- 请求剪贴板访问

- 应用已启动通知
- 应用已关闭通知
- 应用已添加通知
- 应用已移除通知

### 使用场景

需要编程方式启动应用或管理应用列表时。

## org.desktopspec.ApplicationManager1.Application

### 定位

单个应用对象接口，面向需要查询特定应用属性和状态的调用者。

### 功能能力总结

- 读取应用 ID
- 读取应用名称
- 读取应用图标名
- 读取应用显示名
- 启动此应用
- 查询应用是否运行中
- 获取应用窗口信息

### 使用场景

需要查询特定应用的属性、启动应用或获取窗口信息时。

## org.desktopspec.JobManager1.Job

### 定位

异步操作跟踪接口，面向需要跟踪应用启动这类耗时操作状态的调用者。

### 功能能力总结

提供取消异步操作和查询操作状态的能力。

### 使用场景

需要在发起异步操作后跟踪或取消该操作时。

## org.desktopspec.ObjectManager1

### 定位

标准对象管理接口，面向需要获取全部应用对象列表的调用者。

### 功能能力总结

提供获取所有被管理应用对象的方法，返回应用对象路径与接口属性的映射。

### 使用场景

需要一次性获取所有应用对象及其属性时。
